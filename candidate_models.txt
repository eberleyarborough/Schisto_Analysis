This text file contains a list of all of the schisto models that have been 
run thus far (3.10.2026):

For PREVALENCE:
  1. Bernoulli GAM: Age + Average BCS + TWI + MSI + EVI + Soil + f(fire)
    - Ran twice, with both RW1 and RW2 for f(fire)
    - Justification: there was an obvious non-linear pattern between disease
    status and weighted distance to fire, but we needed to assess whether RW1 or
    RW2 fit better.
  2. Bernoulli GAM: Same as above, but with SRF
    - Ran twice, with updated priors for runthrough 2
  3. Bernoulli GLM: Age + SRF
    - Ran twice, with updated priors for runthrough 2
    - Justification: To determine if there was any interaction between covariates
    and the SRF
  4. Bernoulli GAMM: log1p(Age) + Average BCS + TWI + MSI + EVI + Soil + f(fire) +
                        SRF.s OR SRF.n
    - Ran twice, with updated priors for runthrough 2
    - Justification: age (years) is very right-skewed, so a log1p transformation
    feels more appropriate to use; for separate North vs South SRFs, outputs from
    the first 3 models seemed to appear to potentially mask more local aucorrelation
    patterns in the north
  5. Bernoulli GAM: Same as models 1 & 2 above (with log1p(age)), but with smoothers of the order
  RW2 included for each environmental covariate
    - log1p(Age) + Average BCS + f(TWI) + f(MSI) + f(EVI) + f(Soil) + f(fire)
               +/- SRF
    - Justification: it is unlikely that there is a perfect linear pattern with
    these covariates, which are spatial in nature, and may change at different
    rates in different locations within the park.
  6. Bernoulli GAM: Same as 5, but with RW2 smoothers for fire, TWI, and MSI (since
  seemed non-linear after candidate model 5).
    - log1p(Age) + Average BCS + f(TWI) + f(MSI) + EVI + Soil + f(fire)
               +/- SRF
    - Justification: model 5 overfit the model, and based off of smoother plots
    for all environmental covariates, EVI and soil appeared more linear, whereas
    MSI, TWI, and fire had more non-linear effects.

SRF priors and mesh settings for these models have been:
  - Run 1:
    - Mesh resolution = 25km 
    - Range prior = 37, 0.05
    - sigma_u prior = 2, 0.05
    - RW1 prior = 2, 0.05
    - Number of smoother knots = 20
  - Run 2:
    - Mesh resolution = 15km
    - Range prior = 25, 0.95
    - sigma_u prior = 2, 0.05
    - RW2 prior = 2.5, 0.05
    - Number of smoother knots = 20
  - Run 3: 
    - Mesh resolution = 15km
    - Range prior = 25, 0.95
    - sigma_u prior = 2, 0.05
    - RW2 prior = 2.5, 0.05
    - Number of smoother knots = 25

Models 1-3, and 5 are found within the `schisto_inlabru_v1.Rmd` file, and model 4
is located within the `schisto_inlabru_v2.R` file.
